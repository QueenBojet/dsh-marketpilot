# MarketPilot V4（智策）视觉设计系统与前端交互优化规范（`UI_OPTIMIZATION_SPEC.md`）

- **适用范围**：`src/workbench-ui/` 全部核心工作区与全局页面，编译输出至单文件内联产物 `src/harness/v4-page.generated.ts`
- **设计定位**：现代化、高可信度、高信息密度的**工业与工程 AI SaaS 协同工作台**（对标 Linear / Stripe Dashboard / Vercel 与专业工业工程 PLM/CPQ 审阅软件的融合质感）
- **合规约束**：完全兼容 DSH WebServer 严格内联 CSP（无外部字体/CDN/脚本引用，单 `<script>` 内联打包）

## 1. 统一视觉设计系统（Design Tokens & Visual Language）

### 1.1 色彩语义系统（Color Tokens）
摒弃容易造成视觉疲劳的刺眼高饱和荧光色或沉闷后台灰，采用**深海石墨蓝侧边导航 + 明亮冷灰工作画布 + 纯白精致卡片 + 四色工程语义徽章**：

| 语义层级 | CSS 变量 / Token | 色值定义 | 工程界面应用场景 |
| :--- | :--- | :--- | :--- |
| **主工作画布** | `--bg` / `--bg-subtle` | `#f4f6fa` / `#eef2f7` | 主工作区背景、次级内嵌信息盒背景，突出白色面板层级 |
| **卡片与面板表面** | `--panel` / `--line` | `#ffffff` / `#e2e8f0` | `Panel`、`route-card`、`summary-box`、`doc-sheet` A4 纸张容器 |
| **导航深色壳层** | `--nav-bg` | `linear-gradient(180deg, #0b1324 0%, #0f172a 55%, #131f38 100%)` | 左侧固定工程导航栏、当前项目上下文身份卡 |
| **主文本与层级** | `--ink` / `--ink-soft` / `--muted` | `#0f172a` / `#334155` / `#64748b` | 标题、正文、技术参数说明与时间戳辅助信息 |
| **主操作品牌色（工程蓝）** | `--blue` / `--blue-soft` | `#2563eb` / `#eff6ff` | 主操作按钮（`Btn kind="primary"`）、当前激活阶段、候选状态徽章 |
| **已确认/有效态（工程青绿）** | `--teal` / `--teal-soft` | `#0d9488` / `#f0fdfa` | **Human Gate 已人工确认**、依据有效、研究报告完备、V1/V2 正式基线 |
| **待复核/候选态（工程琥珀）** | `--warn` / `--warn-soft` | `#d97706` / `#fffbeb` | 待人工确认、存在待处理建议（Proposal）、估算价格、依据变化预警 |
| **失效/阻断/测试态（工程警示红）** | `--red` / `--red-soft` | `#dc2626` / `#fef2f2` | 审核已过期（`stale`）、**测试价格（`test_data` 非真实）**、执行失败或否决路线 |

### 1.2 字体排印与数值对齐规范（Typography & Tabular Numerals）
- **中英文工程混排字体栈**：`--sans: "Inter", -apple-system, BlinkMacSystemFont, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`
- **等宽技术标识符与金额字体栈**：`--mono: "JetBrains Mono", "SFMono-Regular", Consolas, monospace`
- **字号阶梯**：
  - 页面主标题（`.pagehead h1`）：`23px`，`font-weight: 760`，紧凑字距 `-0.45px`
  - 面板主标题（`.panel-heading h2`）：`15.5px`，`font-weight: 720`
  - 路线与卡片标题（`h3`）：`14px`，`font-weight: 700`
  - 正文与表格内容：`13px`，行高 `1.6`
  - 工程元数据/短码/指纹说明（`.tiny-caption`）：`11.5px`，行高 `1.5`
- **金额与工程参数等宽对齐**：所有 BOM 单价、小计、总价、汇率与数量列统一启用 `font-variant-numeric: tabular-nums`，确保多行数字小数点与千分位严格纵向对齐。

## 2. 核心公共组件与全局壳层改造规范

### 2.1 全局 7 步工程流转状态条（`WorkflowStepper` in `shell.tsx`）
在所有项目工作区顶部（`#page` 首部）注入实时派生自后端 `Overview` 状态的 7 步交互式步进器：
1. **Stage 1 · 需求访谈**（`#/discovery`）：显示 `已确认 (N项)` 或 `待人工确认简报`。
2. **Stage 2 · 资料与支撑**（`#/change`）：显示 `M 资料 · K 固化` 或 `草稿待固化`。
3. **Stage 3 · 多路线初筛**（`#/solution`）：显示 `N 条候选有效` 或 `初筛已过期`。
4. **Stage 4 · 定向研究**（`#/research`）：显示 `X/Y 份报告` 及待复核提示。
5. **Stage 5 · 综合与决策**（`#/solution`）：显示 `已确认 · K 项配置` 或 `路线确认已失效`。
6. **Stage 6 · 成本与报价**（`#/cost`）：显示 `审核 X/3 有效` 或 `成本审核已失效`。
7. **Stage 7 · 文档与交付**（`#/deliver`）：显示 `已发布 V1/V2`、`文档审核有效` 或 `依据变化待同步`。

**联动预警横幅（`.phase-banner`）**：一旦检测到上游依据变动导致下游产物进入 `stale` 状态，`WorkflowStepper` 下方自动展示带一键跳转锚点的琥珀色联动提醒条。

### 2.2 卡片化面板容器（`Panel` in `ui.tsx`）与结构化文本渲染器（`Blocks` in `ui.tsx`）
- **`Panel` 容器**：统一具备白色表面、柔和边框 `#e2e8f0`、`12px` 圆角、顶部标题栏（支持 `title`、`subtitle` 与右侧 `extra` 操作槽），消除原先裸露在灰底上的松散布局。
- **`Blocks` Markdown 渲染器**：支持 `###` 子标题、无序列表、`| 列1 | 列2 |` 工程表格与 `**加粗**` 强调语法的纯前端安全解析渲染（零外部富文本依赖，免疫 XSS），统一应用于探索推理综述、研究报告正文、文档章节预览与 AI 修订建议。

## 4. 交互状态完整性与响应式/无障碍规范

### 4.1 交互状态覆盖（States）
- **空状态（Empty States）**：所有列表、表格与面板在无数据时均通过 `<Empty>` 组件提供具体的下一步操作引导（而非空白区域）。
- **加载与运行中状态（Loading & Running States）**：模型或门禁工具执行期间，顶部与底部浮动运行条（`.run-pill`）实时展示工具名称、状态（`正在运行` / `等待人工确认`）与「取消」按钮；相关触发按钮自动进入禁用态并显示 `已有运行进行中`。
- **禁用原因显式披露（Disabled Reason Disclosure）**：`Btn` 组件支持 `showReason` 属性，当按钮因业务前置条件未满足而禁用时，不仅设置 `title` 提示，还在按钮正下方渲染 `.btn-reason` 微型说明文字，杜绝“按钮点不动又不知道为什么”的黑盒体验。

### 4.2 响应式断点与无障碍（Responsiveness & Accessibility）
- **三档响应式断点验证**：
  - `1440px`（桌面宽屏）：左侧 `248px` 固定导航栏 + 顶部 7 步水平 `WorkflowStepper` + 双栏/三栏高密度工程网格。
  - `1024px`（紧凑笔记本/平板横屏）：自动收缩内边距与网格列宽，保持双栏可读性且零横向滚动溢出。
  - `390px`（移动端竖屏）：左侧导航栏自动隐藏并切换为底部固定 `.mobile-tabbar`，多列表格启用 `.table-scroll` 局部横向滑动，保证 `document.documentElement.scrollWidth <= window.innerWidth`。
- **无障碍与键盘交互**：
  - 弹窗（`Modal`）与抽屉（`Drawer`）均设置 `role="dialog"`、`aria-modal="true"`，并支持 `Escape` 键关闭（Human Gate 待决状态除外，防止误触关闭审核）。
  - `ModelPicker` 弹窗通过 `createPortal(..., document.body)` 挂载于 `body` 根节点，彻底规避顶部 `.topbar` 的 `backdrop-filter` 包含块截断问题。
