# 合成样例

验收测试（`tests/v4-acceptance.spec.ts`）与截图（`tests/v4-preview.spec.ts`）共用 `tests/v4-harness.ts` 中的样例。全部为虚构内容，不是真实客户资料；价格均为 `test_data`（界面标注“测试价格（非真实）”）。原型中的 CALM 数据与金额未写入任何项目。

第一批资料（`第一批资料.txt`，类型 customer_requirement）：

```text
系统应连续监测厂界甲烷浓度。
报警响应时间不超过 5 秒。
监测点位不少于 4 个。
```

第二批资料（`第二批资料.txt`）：响应时间 5 秒 → 2 秒，并新增一条。

```text
系统应连续监测厂界甲烷浓度。
报警响应时间不超过 2 秒。
监测点位不少于 4 个。
新增：数据需上传至园区平台。
```

其余数据：研究问题“厂界甲烷监测点位如何布设？”；候选路线“开路激光路线”“点式传感器路线”；配置“激光监测仪 ×4 台”；成本行单价 1000 → 1200（测试数据）。截图种子另加安装费等测试成本行。
