# 已知限制与风险

## 未验证的外部能力

- 外部模型：本次验证没有可用的模型凭据。深度分析、研究和 AI 对话都已接到 DSH 模型路由（优先级为全局 → 项目 → 本次运行，每次运行都记录实际路由）。测试只验证了模型不可用时会如实失败（`MODEL_ADAPTER_UNAVAILABLE`），界面会提示原因，不会生成内容。真实模型的输出质量没有验证。
- 联网研究：没有配置 Web Provider，所以界面显示“联网：不可用”，联网研究按钮被禁用（`WEB_PROVIDER_UNAVAILABLE`）。只有实际抓取到正文的网页才计为来源。这条规则有单元测试，但没有用真实网页验证过。
- DSH Desktop 实机：本次运行时 Desktop 没有启动。截图来自隔离的回环测试服务，它加载的是同一个插件和同一套 V4 路由。Desktop 入口“打开 V4 独立工作台 ↗”有渲染测试，但没有手动点击验证过。旧 README 记录过本机 `pnpm dsh --version` 报缺少 `tsx`，Web 启动命令本次也没有实际运行。

## 数据与模板

- 公司 DOCX 模板：目前没有公司提供的模板。系统支持上传 .docx 模板（占位符和章节槽位）；没有上传时使用内置的中性版式，它不代表公司格式。
- 价格：样例和截图里的价格全部是测试数据（`test_data`），界面标注为“测试价格（非真实）”。供应商核实检查会把它们列为未核实项。系统里没有任何真实报价。
- 汇率：系统不内置汇率。币种混合且缺少汇率时，只给出分币种小计，不给总价。
- 资料解析：V4 上传支持 md、txt、csv、docx、xlsx、pdf。PDF 解析尽力而为，不依赖外部库，扫描件和复杂排版可能提取不到文字，会显示警告。V3 面板的上传仍然只支持 md 和 txt。

## 架构

- 单进程、单用户、只监听回环地址。路由要求同源，修改类请求需要带 `x-marketpilot-request: 1` 请求头，但没有用户认证。不要把服务暴露到局域网或公网。
- 不自动迁移：V4 状态写在项目状态记录的 `v4` 中，第一次写入时才创建。V4 可以读取旧项目；原版 V3.4 会拒绝新增字段，不能直接切换代码回退。已提供复制件上的导出/恢复工具，需先按 [ROLLBACK.md](ROLLBACK.md) 转换数据。它保全最新 V3 数据和全部 V4 增量，但仅支持官方 single-file JSON；不能用于 SQLite/per-record。恢复时删除原项目或破坏 V4 引用会明确阻断。
- Desktop 前置检查已核对实际 JSON 后端、路径、插件 junction 与配置模型，并生成无凭据的隔离 Profile/构建/旧备份复制件；尚未启动克隆 Profile 或验收原生 Desktop 窗口，不能将前置准备当作 GUI 实机通过。
- 已发布版本不可修改；如需更正，只能发布新版本。“已对外发送”需要人工登记（收件人、渠道、导出文件的 SHA-256），系统本身不发送邮件。
- 运行中途进程重启时，未完成的运行会被标记为中断，需要手动重新发起，不会自动续跑。
