# 已知限制与验证边界

最新产品实际操作结果以 [DESKTOP_GUI_REPORT.md](DESKTOP_GUI_REPORT.md) 为准。此前“无模型凭据”“未配置搜索”“Desktop/Word未打开”的阻断已解除。

- AI统一经过DSH subagents；联网经过DSH ctx.web。已实测模型生成、Skill注入和web-search-pro搜索/抓取，不需要DeepSeek搜索密钥。搜索Provider与模型供应商分别配置。2个网页正文成功、1个失败，其中有同名站点噪声；不能因此认定法规研究充分或模型结论真实。
- 搜索插件安装在隔离Profile，未迁移到正式Desktop Profile。已验证Desktop 0.11.0内置DSH 0.2.0-rc.2；仓库DSH 0.2.1-alpha.1不在该搜索插件声明兼容范围。
- 原生Desktop实测采用安装版私有复制件，修改复制件的数据目录、端口与回环绑定，未改正式安装。入口/工作台实际点击通过，不代表正式环境已部署。
- Word已逐页检查本次默认模板技术4页、成本3页，目录直接可见，标题不孤立。没有公司模板，也未穷尽所有自定义模板、字体或Office版本。
- 所有流程写入与报价为test_data，不是真实供应商报价或工程承诺。旧CALM项目复制件只读检查通过；原始/正式数据哈希保持不变。旧artifacts不会自动成为V4文档。
- 上传支持md、txt、csv、docx、xlsx、pdf；本轮实际操作补测文本PDF、TXT、CSV、无文字PDF、损坏DOCX和重复文件。不承诺扫描件OCR、复杂PDF或所有异常组合。
- 混合币种缺少汇率时只给分币种小计；不内置汇率。历史正式版本不可改；更正需发布新版本。“对外发送”仅人工登记，本系统不会发送邮件。
- 单进程、单用户、回环服务；同源校验与修改请求头不等于多用户认证，不适合直接公网部署。
- V4状态首次写入才创建；读取旧项目不写入。原V3.4不接受V4新增字段，回退须按 [ROLLBACK.md](ROLLBACK.md) 转换，仅支持官方single-file JSON。已验证复制件CLI转换/恢复，未实测V3.4 GUI往返。
- 进程重启会将未完成运行标记为中断，需要手动发起，不自动续跑。本次已完成内容和V1/V2/V3实际重启保留。
