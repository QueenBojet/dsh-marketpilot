# MarketPilot 比赛演示脚本

> 适用版本：V3.0 Phase 5（2026-10-09）
> 演示环境：DSH Desktop + GLM-5.3（zai Provider，max reasoning effort）
> 演示项目：可使用已有的「V3P2 自验收 04:46」或现场新建

## 演示前准备（5 分钟）

1. 确认 DSH Desktop 已启动，模型选择 GLM-5.3 / reasoning effort max。
2. 左侧边栏确认「MarketPilot 智策」图标可见。
3. （可选）准备一份 .md 格式的客户需求文件。

## 演示流程（约 10 分钟）

### 开场：主工作区（1 分钟）

> **说辞**：MarketPilot 是 DeepSeek Harness 的独立业务插件，提供从客户资料到投标方案的完整工作流。它运行在 DSH 的原生主面板中，不修改任何 Harness 核心代码。

- 点击左侧「MarketPilot 智策」图标 → 展示全宽主工作区。
- 指出首页三张统计卡：真实项目数、待审核事项（占位说明）、进行中任务。
- 点击「我的项目」→ 展示项目列表。

### 第一步：项目与资料（2 分钟）

> **说辞**：我们通过浏览器直接上传 .md 文件——不需要告诉 AI 文件路径，也不需要在服务器上手动操作。

- 新建项目（输入名称 → 点创建）→ 打开项目。
- 进入「01 资料与需求」→ 拖放或选择 .md 文件上传。
- 指出受控上传的边界：仅 .md/.txt、UTF-8 校验、大小限制。

### 第二步：AI 需求提取（2—4 分钟）

> **说辞**：现在我们让 GLM-5.3 以 max reasoning effort 提取客户需求。请注意界面显示的是真实的模型运行步骤和实际耗时——不是模拟的进度条。

- 勾选文档 → 点「开始需求分析」。
- 展示步骤时间线（读取资料 → 模型提取 → 需求规范化 → 未知项检测 → 保存与待审）。
- 等待完成（约 100 秒）→ 需求表出现。
- **重点**：指出 6 条 UNKNOWN 条目（"最小检出率未冻结""误报率待确认"等）—— **AI 没有编造数据，而是诚实标记了不确定性**。
- 点一条需求的「详情」→ 展示原始表述与来源定位。

### 第三步：人工审核（1 分钟）

> **说辞**：需求确认是人工门——AI 不能代替人做决定。只有我的明确点击才会更新状态。

- 全选待审核 → 点「确认所选需求」→ 弹出审核对话框。
- 检查问题与详情 → 点「确认」。
- 需求变为"已确认"，出现"需求基线已生成"提示。

### 第四步：技术路线（2 分钟）

> **说辞**：系统根据已确认需求生成候选方案，并以矩阵展示每条需求的覆盖程度。

- 进入「04 技术路线」→ 点「生成候选路线」（约 30 秒）。
- 展示 3 张候选卡片（名称/组成/未知/证据数）。
- 展示**需求覆盖矩阵**：绿色=完全覆盖，琥珀=部分覆盖。
- 选择一条路线 + 填写理由 → 「提交路线决策」→ 人工门确认。

### 第五步：方案生成（2 分钟）

> **说辞**：确认路线后，AI 生成完整技术方案。注意方案保留了所有 UNKNOWN 条目——不会把未验证的参数伪装成承诺。

- 进入「05 方案生成」→ 点「生成技术方案」（约 90 秒）。
- 点「预览」→ 展示 Markdown 安全渲染（多级标题、需求 UUID 引用、UNKNOWN 章节）。
- **重点**：指出"设计边界与待确认条件"章节——这是产品核心价值。

### 第六步：投标合规（2 分钟）

> **说辞**：最后是投标符合性审查。系统强制执行一条规则：没有已核验证据的条款不能标为"满足"。

- 回到「01 资料与需求」上传 tender.md（kind=tender）。
- 进入「06 投标检查」→ 勾选文档 → 「抽取招标条款」（约 10 秒）。
- 点「符合性审查」→ 展示结果。
- **重点**：无证据条款保持"待确认"而非"满足"——证据闸门在起作用。

### 收尾（30 秒）

> **说辞**：MarketPilot 的核心是证据驱动——每一个结论都有来源，每一个不确定都被标记，每一个关键决策都由人做。

- 回到项目概览 → 展示阶段条（多阶段绿色完成）。
- 进入「项目成果」→ 展示 Requirement Baseline.md 和 Solution.md 预览。

## 备用方案

- 模型超时（>10 分钟）：降低 profile 的 modelTimeoutMs 或使用离线演示（`pnpm marketpilot:demo:smoke`）。
- 网络不可用：全部流程在本地完成，仅需 DSH Desktop 已启动。
- 已有演示数据：V3P2 项目包含完整的全链路结果（需求→路线→方案→投标），可直接展示成果而不必现场运行模型。

## 关键数据

| 环节 | 真实耗时 |
|---|---|
| 需求提取 | ~100 秒 |
| 候选路线生成 | ~26 秒 |
| 方案生成 | ~93 秒 |
| 招标条款抽取 | ~8 秒 |
| **全链路**（含人工） | **~5.5 分钟** |
