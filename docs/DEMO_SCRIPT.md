# MarketPilot V3.3 比赛演示脚本

日期：2026-10-11（Asia/Shanghai）。目标时间 **8分30秒，硬截止10分钟**。
使用安装版 DSH Desktop、原生 MarketPilot 主面板和真实后端。当前路由以界面为准：`zai / glm-5.3-flash / max`，不能口述为已复验非 Flash 的 `glm-5.3`。

## 演示前准备（不计入现场时间）

1. 完全退出 Desktop 托盘进程后启动最终构建；有活动任务或人工门时不要重启。关闭窗口可能只是隐藏到托盘。
2. 使用「CALM 漏油监测桌面版演示」作为预备案例。M5 新生成版本、调用次数、耗时及审核状态见 `gui-acceptance/v3.3-m5/m5-live-facts.json`。只有实际审核完成的成果才可称为已审核；draft 明确称草稿。
3. 准备现有「CALM 正式演示（现场确认用）」待审需求批次，先核对批次 runId 和来源。现场唯一写入节点：人类确认需求。不宜改变数据时，展示审核摘要后取消，明确说明未提交。
4. 准备「V3.3 M1 GUI 空项目 · synthetic QA」展示前置条件；准备新的绝对 `.md` 导出路径，已有路径不可覆盖。
5. 使用1440×900或1366×768、浅色；确认1024紧凑导航和深色已通过终验。上传只支持有效UTF-8 `.md/.txt`。
6. 提前运行模型生成。**现场不运行方案生成**：多章任务可能超过10分钟，历史11分钟结果不能作为现场93秒承诺。现场单节点选择人工审核，不依赖网络时延。

## 现场流程

| 时间预算 | 点击与说明 | 核对事实 |
|---|---|---|
| 0:00—0:45 | 打开首页，进入CALM概览；切专业/引导模式 | 同一项目和服务端阶段；下一步来自真实缺项 |
| 0:45—1:30 | 打开空QA项目，进入技术路线与方案 | 无confirmed需求和无人工Decision不能生成，禁用原因可读 |
| 1:30—2:30 | 打开待审CALM，选本批需求，查看来源原文与MUST筛选 | 选择范围随筛选清空，runId属于当前批；UNKNOWN保留 |
| 2:30—3:15 | 唯一写入节点：人类确认需求，阅读真实Human Gate再确认；或明确取消 | 人工确认前不改变状态；步骤与耗时来自后端 |
| 3:15—4:15 | 完整CALM的情报研究与证据审查，点击EVD/REQ跳转 | 本地提取，缺单位/条件显示UNKNOWN；synthetic标注；联网unverified |
| 4:15—5:30 | 技术路线切矩阵/摘要，展开候选、填写理由、查看决策摘要，再关闭 | 展开不误选；覆盖不代表认证；不改变既有Decision |
| 5:30—6:45 | 打开M5新真实模型方案，查看摘要/目录/风险/引用，再切历史版本 | 新版依赖current；旧版untracked；历史原文与编号保留 |
| 6:45—7:45 | 投标条款与补证；点击导出符合性矩阵，空项目展示可选招标 | 无已核验事实不能compliant；导出定位正确成果；不启动第二个写入节点 |
| 7:45—8:30 | 任务中心看持久化历史、调用数、耗时，再回概览 | 不把遗留等待当可回答的门；审批与实际导出分别说明 |

预留1分30秒处理延迟；到9分直接收尾。上述为预算，自动导航回归耗时不是人类完整口述彩排的实测时间。

## 备用流程

- 模型或网络故障：展示预生成真实版本和失败/恢复记录，不声称现场调用成功。本地阅读和人工节点可演示；新模型生成仍需Provider网络。
- 无搜索Provider：保持联网unverified，展示本地研究，不用搜索摘要、第三方代理或离线fixture冒充抓取。
- 待审样例已确认：展示历史批次；现场改为打开决策摘要后关闭，明确是预览。
- 没有已审核的新成果：展示draft与审阅入口，不以自动化代替人的批准。
- 离线smoke：`pnpm --config.verify-deps-before-run=false marketpilot:demo:smoke`；离线模型与显式模拟人工只证明管线/模板/持久化，不代表在线GLM或真实人审。
