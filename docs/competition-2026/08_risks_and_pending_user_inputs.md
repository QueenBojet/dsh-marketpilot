## 本批发现的资料使用风险

1. **原件缺口**：fixture声明历史读过原件，本批未见原件，尚不能独立复核真实性与转写完整性。合成输入与业务摘录在主案例中并存，必须按资料类型讲述。
2. **业务基准需重核**：14条confirmed中包括材料声明 / 约束性表述，未必全部适合作为客户功能需求基准；重复或组合UNKNOWN记录不能直接计算独立问题数量。由人确认统计单位后再评估质量。
3. **文件状态分离**：ART-06已批准并正式导出，但正文仍是原草稿标题。不要为统一表述修改既有存档；若后续需公开附件，应生成有来源说明的脱敏衍生副本，由用户审阅，并保留原始哈希。
4. **内部标识**：ART-06正文检测到4处call/item审计标记，另有内部短片段；事实JSON含UUID / 本机路径。新索引未复制这些值，原始文件不应直接作为公开附件。
5. **截图范围**：8张目视检查的图中，原生批准图含其他聊天标题；方案阅读器含审核标识、输入指纹和内部片段；任务页混有其他项目及历史等待。需要裁切 / 脱敏副本和准确图注，不能改写原证据。
6. **历史时点**：本批未查询实时Desktop状态；2026-10-11的待审批次、Provider、成果状态不能自动当作2026-10-12仍未变化。后续需只读核对时另按批准范围执行。
7. **工程数字不可合并**：初轮258、补修39 / 33是不同测试范围；GUI31、补修9和目录50张是不同统计。旧README环境描述、早期阶段停止声明不能覆盖M5最新事实。
