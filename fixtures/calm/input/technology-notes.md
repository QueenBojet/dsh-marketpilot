# 匿名技术路线研究摘录

来源为既有工程方案中的技术描述。这些内容是候选方法，不能单独证明某一设备型号满足现场性能。

## 水面候选方法

水面路线可采用油膜监测雷达发现异常，再用红外热成像和可见光进行确认，辅以姿态和环境信息。雷达、红外及可见光均有海况、遮挡、目标对比度等适用边界，需联合验证。

## 水下候选方法

水下路线可采用成像声纳观察异常羽流，配合 UV 荧光油份传感器确认局部油份，并使用温度信息辅助判读。声纳需要评估背景散射，油份传感器受采样位置及流场影响，温度信息不能独立作为漏油结论。

## 集成与验证

多源信息在边缘侧形成事件，上传告警、原始片段和复核结论。先做现场基线采集与受控验证，再冻结阈值和验收标准。水面、水下覆盖能力以及不同传感器组合的成本、维护量需比较后由人工决定。

本摘录没有可核验的厂家型号、认证或业绩数据；这些项目必须保留 UNKNOWN。
