# 匿名 CALM 监测需求摘录

本材料根据已读取的水面方案 DOCX 和水下 V4.0 Markdown 做最小脱敏整理，仅用于 Workflow 演示。移除了客户、地点、设备数量、部署尺寸、预算及报价。以下表述须经项目人员确认后才能成为 Requirement Baseline。

## 监测目标

- 系统应支持 24 h 连续监测。
- 监测对象包含 CALM 周边水面漏油和水下管系漏油。
- 通过多源融合、报警分级和人工复核降低单一传感器误报风险。
- 报警应关联事件时间、传感器数据与图像，并支持事件留存和回放。
- 系统应适应海工环境，设计时考虑海浪、潮流、盐雾、姿态变化和维护可达性。
- 边缘处理应支持通信中断期间的本地缓存和恢复后的数据补传。

## 待确认条件

- 最小检漏率未冻结，需通过现场试验和验收协议确认。
- 误报率、检出概率和响应时间的保证值未冻结。
- 报警留存周期、接口协议及供电条件待确认。
- 防爆、防护和船级等认证的适用范围及证明材料待确认。

既有方案中的覆盖与响应建议不作为已确认验收保证。
